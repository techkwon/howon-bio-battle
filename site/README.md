# 생명 기술 대작전 — 교사 사용법 (한 장)

교사 화면(**진행판** `host.html`) 하나 + 학생 크롬북(**조종기** 첫 화면) 1인 1대. 이름은 받지 않는다 — **방 코드 + 번호(1~30)** 만.

## 수업 전에 한 번만

1. **보안 규칙 올리기** — Firebase 콘솔 → Realtime Database → 「규칙」 탭 → `database.rules.json` 내용을 통째로 붙여 넣고 **게시**. (안 올리면 「방 만들기」에서 *쓰기를 막았어요* 가 뜬다)
2. 콘솔 → Authentication → 로그인 방법에 **익명** 이 켜져 있는지 확인
3. 사이트(`site/` 폴더)를 Netlify 에 올린다. 주소 예: `https://○○○.netlify.app`
   - 진행판: `https://○○○.netlify.app/host.html` · 학생: `https://○○○.netlify.app`
4. 연습: 교사 PC 에서 진행판을 열고, **다른 브라우저나 시크릿 창**에서 학생 화면을 열어 들어가 본다(같은 창에서 열면 같은 사람으로 인식된다)

## 수업 흐름

| 단계 | 교사(진행판) | 학생(조종기) |
|---|---|---|
| 1. 방 만들기 | 반 · 팀 크기(4명/6명) · 팀 정하는 방식 고르고 **방 만들기** | — |
| 2. 들어오기 | 화면에 주소 · **방 코드(큰 숫자 4개)** · 번호 격자 | 주소 열고 방 코드 + 내 번호 → 들어가기 |
| 3. 팀 정하기 | **팀 정하기 ▶** | 학생이 고르기: 30초 안에 팀 버튼(꽉 찬 팀은 잠김) |
| | 마감 뒤 결과 확인 → 고칠 번호는 **끌어다 놓기** 또는 *번호 누르고 → 팀 이름 누르기* → **이대로 확정** | 못 고른 학생은 빈자리에 🎲 무작위 (팀 인원 차이 최대 1명) |
| 4. 게임 | 점수판 오른쪽 **차시 탭(13 · 14 · 15 · 16차시)** 에서 그 차시 게임 고르기 → 설명 10초(**바로 시작** 가능) → 게임 | 화면의 큰 버튼만 누른다 |
| 5. 끝 | **수업 끝 ▶** → 시상 화면 → **방 닫고 끝내기**(방이 지워진다) | 「수업이 끝났어요」 |

### 13차시 게임
- **🎈 효모 풍선 대결** (약 6분) — 3라운드: **1라운드 가장 크게 → 2라운드 🎯 25cm 맞히기 → 3라운드 🎯 30cm 맞히기**(목표에 가까운 팀이 이김 · 정수 cm 로 순위). 팀이 투표로 물 온도(10 · 25 · 40 · 70℃)와 설탕(없음 · 조금 · 많이)을 고른다(투표 20 · 15 · 15초). 모두 고르면 3초 뒤, 팀마다 한 명씩만 남으면 6초 뒤 마감(**+10초** · **투표 마감** 단추). 30초 동안 풍선이 부푼다 — 가장 크게(42cm) 부풀면 칸을 가득 채운다. 발효 처음 8초 동안 크롬북에 **「우리 풍선 몇 cm?」**(15 미만 · 15~24 · 25~34 · 35 이상) — 맞힌 팀원 비율만큼 라운드마다 최대 +1점. 라운드 사이 화면에 *되먹임* 한 줄. 끝에 **시스템 네 칸 카드**(투입 · 과정 · 산출 · 되먹임)
- **🥬 김치 숙성 타이밍** (약 4분) — 3라운드(냉장고 4℃ → 실온 20℃ → 냉장고인데 **깜짝 정전**(정전 뒤 실온보다 1.5배 빨리 익음)). 각자 「꺼내!」 한 번. 가장 맛있을 때(숙성도 60)에 가까울수록 점수, 팀 = 평균(못 누르면 0점 · 팀원 3명 이상이면 가장 낮은 점수 하나는 빼고 평균). 라운드가 끝나면 1.5초 동안 「결과 모으는 중」 — 와이파이가 느려 늦게 도착한 「꺼내!」도 제때 누른 것이면 센다. 결과 화면에서 번호가 겹치면 옆으로 비켜 서고 아래 눈금이 실제 자리. 끝에 발효 식품 카드

점수: 라운드마다 1위 10 · 2위 8 · 3위 6 · 4위 5 · 5위 4 · 6위 3 · 7위 2 · 8위 1. 효모 2 · 3라운드에서 목표 cm 를 딱 맞히면 +2, 예측은 세 라운드 합을 반올림해 더한다.
**반 대항 기록판**(가장 큰 풍선 등)은 이 교사 PC 브라우저에만 남는다(반 · 팀 이름만).

> 프로젝터(교사 PC)는 **가능하면 유선(랜선)** 으로 연결한다. 진행판이 끊기면 학생 입력도 멈춘다.

## 이럴 땐

| 상황 | 할 일 |
|---|---|
| 학생이 번호를 잘못 넣음 | 대기실 번호 격자에서 그 번호를 눌러 **내보내기** → 학생이 다시 들어온다 |
| 같은 번호로 두 기기가 들어옴 | 나중 기기가 들어오고, 앞 기기에는 「다른 기기에서 접속」이 뜬다(팀은 그대로 물려받음) |
| 진행판에 **「⚠ ○번 두 기기 — 누가 진짜?」** | 같은 번호가 2분 안에 세 번째로 바뀌면(번갈아 들어오는 장난 · 번호 착각) 자동으로 내보내지 않고 묻는다. 그 번호 학생들에게 크롬북 **위쪽 오른쪽의 「기기 K7」 같은 글자**를 물어 진짜 기기 단추를 누른다 → 다른 기기는 「선생님이 이 기기를 내보냈어요」 |
| 학생 크롬북이 꺼졌다 켜짐 · 새로 고침 | 첫 화면을 다시 열면 **저절로 다시 들어온다**(같은 팀). 격자에 *끊김* 표시가 잠깐 보일 수 있다 |
| 늦게 온 학생 | 들어오면 가장 작은 팀에 자동으로 들어간다(진행판에 알림) |
| 팀 인원을 바꾸고 싶다 | 점수판의 **팀 고치기**(점수 유지) · **팀 처음부터**(점수 0) |
| 기기 없는 팀이 있다 | 게임 중 위쪽 **대신 누르기** → 팀이 말하는 대로 교사가 누른다 |
| 진행판을 실수로 닫음 · 새로 고침 | 다시 열면 **이어서 하기 ▶** (8시간 안) |
| 한 명이 안 골라 투표가 안 끝남 | **투표 마감 ▶** 을 누른다(안 고른 팀은 🎲 무작위) |
| 같은 알림이 여러 번 | 알림은 화면 위쪽 가운데에 뜨고, 같은 글은 하나로 합쳐 「×2」처럼 센다(아래쪽 단추를 가리지 않는다) |
| 접속 인원이 출석 인원보다 많음 | 한 학생이 기기 두 대로 들어왔거나 번호를 잘못 넣었다. 번호 격자에서 확인 |
| 와이파이가 끊김 | 위에 빨간 띠가 뜬다. 다시 붙으면 저절로 이어진다. 오래 끊기면 **비상 모드로 바꾸기** |
| 처음부터 인터넷이 안 됨 | 시작 화면 **비상 모드** → 팀 수 입력 → 학생 화면 없이 교사가 팀마다 **대신 누르기** |

## 지켜지는 것
- 학생 이름 · 연락처를 받지 않는다. 화면에는 「7번」과 팀 이름만
- 점수 · 팀 배정 · 판정은 진행판만 한다. 학생은 자기 입력 칸에만 쓸 수 있다(보안 규칙)
- 「방 닫고 끝내기」로 방이 지워지고, 진행판을 열 때 만든 지 하루 넘은 **이 PC에서 만든 방**도 지운다
- 외부 글꼴 · 이미지 · CDN 없음(Firebase 프로그램도 사이트 안에 함께 들어 있다)

새 게임 만들기(개발자용)는 `GAMES.md`.
